## SymbolicSINDyAE

This repository contains the code developed for the Master's thesis **[Data-driven discovery of dynamical systems through Symbolic-SINDy](https://www.politesi.polimi.it/handle/10589/251217)**.

In particular, it focuses on the **high-dimensional experiments** developed as part of the [MDLoop2](https://github.com/mattiagast/MDLoop2) framework.

A dedicated project structure and computational environment are maintained to ensure compatibility and avoid dependency conflicts with the standard-dimensional experiments.
